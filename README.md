# nlp-internet-genres-bert
# Классификация интернет-жанров и анализ тональности текстов с использованием RuBERT

## 📌 Описание проекта
Проект посвящен автоматическому анализу и классификации текстовых корпусов различных интернет-жанров (комментарии, посты социальных сетей, блоги). В основе решения лежит дообучение (Fine-Tuning) современной архитектуры трансформеров для учета глубокого контекста интернет-дискурса.

**Сфера применения в госсекторе Москвы:** Автоматизация разбора обращений граждан на городские порталы (например, портал «Наш город», «Активный гражданин»), интеллектуальная категоризация обратной связи, мониторинг цифровой среды и контент-анализ медиасферы.

## 🛠️ Стек технологий
* **Language:** Python 3.10+
* **NLP & Deep Learning:** Hugging Face Transformers, PyTorch, Natasha (лемматизация)
* **Data Science:** Pandas, NumPy, Scikit-Learn
* **Визуализация:** Matplotlib, Seaborn

## 🚀 Основные этапы реализации
1. **Предобработка данных:** Сбор текстовых корпусов, очистка от шума, токенизация и лемматизация специфичного интернет-текста с сохранением семантики.
2. **Эмбеддинги:** Извлечение контекстных векторных представлений с помощью предобученной модели `RuBERT`.
3. **Моделирование:** Тонкая настройка (Fine-Tuning) классификатора на базе PyTorch для распознавания жанровых и стилистических признаков текста.
4. **Оценка качества:** Модель достигла целевых метрик точности (Accuracy/F1-score), успешно справляясь со сложным сленгом и смешанными стилями.
